### 🗂️ File Naming Convention & Indexing
For this textbook, solutions are indexed by page number following the pattern:

$$\mathbf{σ[\text{Page}]\_[\text{Type/Number}]}$$

- **`σ#_α#`** $\rightarrow$ **Numbered Exercise** (e.g., `σ118_α10.pdf` = Page 118, Exercise 10).
- **`σ#_θεωρημα_#`** $\rightarrow$ **Full Theorem Proof** (e.g., `σ170_θεωρημα_1.pdf`).
- **`σ#_πορισμα_#`** $\rightarrow$ **Corollary Proof** (e.g., `σ175_πορισμα_1.pdf`, `σ176_πορισμα_ΙΙ.pdf`).
- **`σ#_ασκηση`** $\rightarrow$ In-text examples and unnumbered application problems.
