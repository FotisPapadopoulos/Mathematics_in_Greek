### 🗂️ File Naming Convention & Indexing
All solution PDF files follow a systematic Greek nomenclature scheme for direct mapping back to the textbook:

$$\mathbf{κ[\text{Chapter}]\_σ[\text{Page}]\_[\text{Type/Number}]}$$

- **`κ#_σ#_α#`** $\rightarrow$ **Exercise** (e.g., `κ1_σ45_α1.2.pdf` = Chapter 1, Page 45, Exercise 1.2).
- **`κ#_σ#_θεωρημα_#`** $\rightarrow$ **Full Theorem Proof** referenced in text (e.g., `κ1_σ22_θεωρημα_1.5.pdf`).
- **`κ#_σ#_εφαρμογη_#`** $\rightarrow$ **Application / In-text Example** (e.g., `κ1_σ27_εφαρμογη_1.pdf`).
- **`κ#_σ#_υποσημειωση` / `παραδειγμα`** $\rightarrow$ Explanatory footnotes, remarks, and non-numbered examples.
