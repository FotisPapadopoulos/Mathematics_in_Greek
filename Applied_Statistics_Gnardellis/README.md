### 🗂️ File Naming Convention & Indexing
All solution PDF files follow a systematic Greek nomenclature scheme for direct mapping back to the textbook:

$$\mathbf{κ[\text{Chapter}]\_σ[\text{Page}]\_[\text{Type/Number}]}$$

- **`κ#_σ#_α#`** $\rightarrow$ **Numbered Exercise** (e.g., `κ3_σ111_α3.8.pdf` = Chapter 3, Page 111, Exercise 3.8).
- **`κ#_σ#_αποδειξη`** $\rightarrow$ **Mathematical Proof** (e.g., `κ3_σ116_αποδειξη_μεταθεσεις_με_ομοια_αντικειμενα.pdf`, `κ4_σ136_αποδειξη_μεσου_διωνυμικης_κατανομης.pdf`).
- **`κ#_σ#_ασκηση`** $\rightarrow$ In-text examples and unnumbered application problems.
