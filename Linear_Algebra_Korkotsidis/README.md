### 🗂️ File Naming Convention & Indexing
All solution PDF files follow a page-based nomenclature scheme for direct mapping back to the textbook:

$$\mathbf{σ[\text{Page}]\_[\text{Type/Number}]}$$

- **`σ#_α#`** $\rightarrow$ **Numbered Exercise** (e.g., `σ137_α12.pdf` = Page 137, Exercise 12, `σ145_α4.1.pdf` = Page 145, Exercise 4.1).
- **`σ#_θεωρημα_#`** $\rightarrow$ **Full Theorem Proof** (e.g., `σ157_θεωρημα_4.4.pdf`).
- **`σ#_αποδειξη`** $\rightarrow$ **Mathematical Proof** of proposition or formula (e.g., `σ157_αποδειξη.pdf`).
